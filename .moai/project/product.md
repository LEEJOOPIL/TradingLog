# TradingLog — 제품 개요

## 한 줄 요약

Google Sheets + Google Apps Script 기반의 개인용 투자 기록 관리 웹앱. 금·은·암호화폐 등 자산의 매입 내역을 기록하고, 현재가를 수동으로 입력해 수익률과 손절 손실을 추적한다.

## 문제 정의

- 여러 자산(금·은·비트코인·이더리움 등)에 분산 투자할 때, 매입 단가·수량·현재가·손익을 한곳에서 보기가 어렵다.
- 실시간 시세 API를 연동하려면 별도 인증·요금·API 한도 관리가 필요해, 개인용 도구로는 과한 복잡도다.
- 손절 기준을 정해두고도 실제로 손절가에 도달했을 때 반영이 누락되기 쉽다.

## 해결 방식

- Google Sheets를 데이터 저장소로, Google Apps Script를 서버 로직으로 사용해 별도 배포 인프라 없이 브라우저 웹앱을 제공한다.
- 가격은 **전 자산 수동 입력**을 원칙으로 한다 — 외부 API·GOOGLEFINANCE에 의존하지 않아, 인증 설정이나 API 장애를 걱정할 필요가 없다.
- 웹앱의 "현재가 설정" 패널에서 자산 종류별로 한 번에 가격을 반영하고, 개별 행은 모달 편집으로 세밀하게 조정한다.
- 포함 여부(J열) 체크박스로 손절 실현 여부를 표시하면, 종합 요약이 자동으로 손절가 기준으로 재계산된다.

## 타깃 사용자

- 여러 종류의 자산(귀금속 + 암호화폐)을 함께 관리하는 개인 투자자 1인.
- Google Sheets에 익숙하지만, 매번 수식을 손으로 고치고 싶지 않은 사용자.
- 외부 서비스에 API 키를 등록하거나 요금을 지불하고 싶지 않은 사용자.

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 매입 내역 관리 | 날짜·자산구분·매입가·수량·투자이유를 행 단위로 기록 |
| 자동 계산 수식 | 총매입금액, 수익률, 손절액을 자동 계산 (매입가·수량·현재가·손절가 입력 시) |
| 현재가 일괄 설정 | 자산 종류별로 현재가를 한 번에 입력해 전체 행에 반영 |
| 자산 종류 동적 관리 | 기본 7종(금·은·비트코인·이더리움·솔라나·USDT·USDC) 외에 자유롭게 추가·삭제 |
| 손절 실현 처리 | 체크박스(포함여부)로 손절가 기준 반영 여부를 제어 |
| 종합 요약 카드 | 총 매입금액·총 평가금액·총 수익금액·종합 수익률을 웹앱에서 실시간 확인 |
| 낙관적 렌더링 | 저장·삭제·현재가 적용 시 서버 응답 전에 UI를 먼저 갱신해 체감 속도 향상 |

## 현재 상태

- SPEC-ASSET-001 (자산 종류 동적 관리): 완료
- SPEC-UI-001 (KRW 환율 변환 표시 기능): 완료 — 이후 REQ-005·REQ-006(웹앱 KRW 카드) 철회, 시트 수식만 유지
- 두 SPEC 모두 완료 상태로, 현재 진행 중인 개발 작업은 없음
