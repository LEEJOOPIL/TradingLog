# SPEC-UI-001 인수 기준

## 개요

본 문서는 SPEC-UI-001 KRW 환율 변환 표시 기능의 인수 조건을 Given/When/Then 시나리오로 정의한다.
모든 시나리오가 통과해야 구현 완료로 인정한다.

---

## 시나리오 1: 정상 시트 초기화 시 KRW 행 존재

**Given** TradingLog 스프레드시트가 열려 있고 M7, N7, M8, N8 셀이 비어 있는 상태에서,

**When** 사용자가 메뉴 "투자 관리 > 🛠 시트 초기화"를 실행하면,

**Then** M7 셀에 "총 평가금액(KRW)" 텍스트가 표시되고, M8 셀에 "환율(USD/KRW)" 텍스트가 표시되며, N7과 N8 셀에 각각 GOOGLEFINANCE 수식이 설정되어 있어야 한다.

---

## 시나리오 2: N7 수식이 N4 × 환율로 계산됨

**Given** N4(총 평가금액 USD)에 유효한 숫자 값이 있고 GOOGLEFINANCE("CURRENCY:USDKRW")가 데이터를 반환하는 상태에서,

**When** 시트가 자동 갱신되거나 "📊 수식 전체 갱신" 메뉴가 실행되면,

**Then** N7 셀의 값은 `N4 × N8(환율)` 과 일치해야 하고, N7 값은 정수 포맷(`#,##0`)으로 표시되어야 한다.

---

## 시나리오 3: GOOGLEFINANCE 데이터 미수신 시 대체값 표시

**Given** GOOGLEFINANCE("CURRENCY:USDKRW")가 오류를 반환하거나 빈 값을 반환하는 상태에서(예: 장 마감, API 지연),

**When** N7 또는 N8 수식이 평가되면,

**Then** N7 셀과 N8 셀에는 오류 표시(#N/A, #VALUE! 등) 대신 "-" 문자열이 표시되어야 한다.

---

## 시나리오 4: 기존 N3–N6 수식에 영향 없음

**Given** N3, N4, N5, N6에 기존 수식이 올바르게 설정되어 있는 상태에서,

**When** `initSheet()` 또는 `updateAllFormulas()` 가 실행되면,

**Then** N3, N4, N5, N6의 수식 내용은 실행 전과 동일하게 유지되어야 하며, 어떠한 셀 값도 변경·삭제되지 않아야 한다.
